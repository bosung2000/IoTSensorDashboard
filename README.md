# IoT Sensor Dashboard

**매장 유동인구 센서 1,000대를 실시간으로 세고, 그 숫자를 믿을 수 있게 지키는 관제 시스템.**

C# / .NET 8 · WPF 데스크톱 3앱 · MQTT · SQLite

---

## 이 프로젝트가 다루는 문제

센서 대시보드를 "속성"으로 정의하면 끝이 없다. 그래서 **부정으로** 정의한다.

> 예쁜 차트가 없어도 이 시스템은 이 시스템이다.
> 하지만 **수집된 숫자가 거짓이면** 이건 더 이상 데이터 대시보드가 아니라
> **그럴듯한 거짓말 생성기**다.
>
> → **본질 = 숫자의 진실성**

관리자는 이 숫자로 인력 배치·매장 평가·영업시간을 정한다.
숫자가 **조용히** 틀리면 잘못된 의사결정이 나가고, 아무도 그 사실을 모른다.

그래서 이 저장소가 진짜로 만드는 것은 기능이 아니라 **깨지지 않는 규칙**이다.

### 🧭 한 줄 규칙

> ## 모르는 것을 아는 것처럼 그리지 마라.
>
> `0` · `100%` · `정상` 은 전부 **주장**이다.
> 측정한 근거가 없으면 **「측정 불가」**라고 쓰는 편이 언제나 낫다.

이 문장이 아키텍처부터 화면 문구까지 전부를 관통한다.

## 불변식 — 절대 깨지면 안 되는 것

전부 `Core` 가 소유한다. 플러그인(센서 코덱·수집 채널·저장소)은 **의도적으로 멍청하게** 만들어,
새 종류가 아무리 꽂혀도 이 규칙들을 깰 수 없게 한다.

| # | 규칙 | 깨지면 |
|---|---|---|
| **I1** | 수집된 이벤트는 유실·중복 없이 **정확히 1회** 저장된다 | 순단·재전송에서 숫자가 새거나 두 번 세진다 |
| **I2** | 보존창 내 **append-only**, 그 뒤는 집계로 승격 | 집계 버그가 원본을 오염시키거나 저장소가 무한 성장한다 |
| **I3** | 시간 해석이 **전 구간 단일 규약** | 현지시각과 UTC 가 섞여 피크타임을 오판한다 |
| **I4** | 권한 경계는 **절대 새지 않는다** (fail-closed) | 타 지점 데이터 노출 — 되돌릴 수 없다 |
| **I5** | 침묵은 **0이 아니라 「모름」** | 오프라인을 0으로 읽어 "손님이 없었다"로 오판한다 |
| **I6** | 재시작해도 센 값이 **소멸하지 않는다** | 리포트·SLA 가 아예 성립하지 않는다 |
| **I7** | 물리적으로 불가능한 값은 **격리하고 센다** | 글리치 한 건이 하루 통계를 망치고, 아무도 모른다 |

각 규칙은 **앱을 띄우지 않고 도는 자동 게이트**로 못박혀 있다(`tests/…/InvariantGates/`).

### 특히 I5 — 이 시스템에서 가장 자주 틀리는 자리

사각지대가 **세 번 연속** 여기서 나왔고, **세 번 다 분모 문제**였다.

- 가동률 분모가 「관측된 센서」라, 처음부터 죽은 센서가 분모에서 빠졌다 → **950/950 = 100%**
- 사이트를 못 받은 센서를 건너뛰어, 센서가 전부 죽은 매장이 목록에서 **사라졌다**
  (0 표시보다 나쁘다 — 0은 "손님이 없었구나"지만, 사라지면 **"그런 매장이 없구나"**가 된다)
- 장애 이력이 없으면 무조건 **100.000%** — 관제실이 꺼져 있던 매장도 만점

> **비율을 그리는 코드를 보면 반드시 분모의 출처를 묻는다.**
> 「있어야 할 것」인가 「이미 본 것」인가.
> 분모가 관측 기반이면 **처음부터 없는 것은 영원히 안 보인다.**

## 아키텍처

```
        ┌────────────────── Core ──────────────────┐
        │  도메인 · 불변식 · 판정 · 플러그인 계약     │   ← 의존성 0
        └──────────────────────────────────────────┘
              ▲            ▲            ▲
          ┌───┴───┐   ┌────┴────┐  ┌────┴─────┐
          │ Mqtt  │   │ Sqlite  │  │Ui.Common │
          └───┬───┘   └────┬────┘  └────┬─────┘
        ┌─────┴────────────┴────────────┴─────┐
        │  ControlRoom · SensorFarm · Dashboard │   ← 앱은 서로를 코드로 참조하지 않는다
        └───────────────────────────────────────┘
```

**세 줄이 전부다.**

1. **Core 는 아무것도 참조하지 않는다** — NuGet 0개
2. **화살표는 한 방향으로만 흐른다**
3. **앱끼리는 코드로 이어지지 않는다** — 유일한 통신 수단은 MQTT

### 왜 Core 가 순수해야 하나

판정 규칙이 Core 에 있고 Core 가 순수해야 **앱을 띄우지 않고 검증**할 수 있다.
판정이 UI 코드비하인드로 새는 순간 자동 검증이 불가능해지고,
**자동 검증이 없는 판정은 조용히 틀린다.**

> 📌 일반화하면: **"이 숫자가 틀리면 큰일 나는" 판정은 전부 Core 로 꺼낸다.**

## 이 저장소에서 볼 것

기능 목록이 아니라 **판단**을 남기려고 만든 저장소다.

- **계약이 규칙을 강제한다** — `IEventStore` 에 `Update`·`Delete` 가 없는 건 실수가 아니다.
  "하지 말자"는 약속이 아니라 **구조적으로 못 하게** 만든 것이다.
- **실패를 삼킬 수 없게 만든다** — 외부로 나가는 호출은 `void` 를 반환하지 않는다.
  `void` 면 삼킴이 기본값이 되고, **장애를 알리는 장치가 조용히 실패하면 장애가 두 번 일어난 셈**이다.
- **버린 것은 반드시 센다** — 큐가 넘쳐 폐기하든 저장이 실패하든, 카운터가 있고 화면에 이어진다.
  세기만 하고 안 이으면 세지 않은 것과 사용자에게는 똑같다.
- **안심 문구는 측정값에만 붙인다** — 「유실 0」을 쓰려면 **그걸 반증할 수 있는 카운터**가 함께 있어야 한다.
  카운터 없는 안심 문구는 거짓말이 될 준비가 된 문구다.
- **모르면 거부한다** — 권한 배정이 비어 있으면 「전부 보임」이 아니라 「아무것도 안 보임」이다.

커밋 로그와 [설계 공백 대장](docs/spec-gaps.md)에 **왜 그렇게 정했는지**가 남아 있다.
